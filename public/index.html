Movie Terminals

Play with recreations of the computer terminals from famous movies. Type the commands the characters typed, and a few they could have.

  • INTERFACE 2037 READY FOR INQUIRY WHAT'S THE STORY MOTHER?

    Alien 1979

    MU-TH-UR 6000 · USCSS Nostromo

    One of the first terminal interfaces on screen to carry key plot points.

    Its Interface 2037 seems to parse natural English, or else its commands are unusually verbose. Unless you're an extreme Alien fan or have watched it very recently, you'll want to look at the command reference.

  • $ service start tron ADDRESS FILE EMPTY TRON PROGRAM UNAVAILABLE $

    TRON 1982

    Alan's terminal · ENCOM

    At the start of TRON, Alan is trying to work on his Tron program, a security program that monitors all contact between internal and external systems on the ENCOM network. Unfortunately for him, the MCP doesn't want any oversight, and his access is suspended.

    The terminal gets very little screen time, so this one is padded with fun things to do. It assumes ENCOM's developer terminals ran a variant of Unix, one with some system tools of the "future" (like service).
