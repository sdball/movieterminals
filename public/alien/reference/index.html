The address matrix

Where the terminal starts.

Like Dallas in the film, you start at the overmonitoring address matrix and pick Interface 2037 to talk to Mother.

KeyWhat happens
← ↑ ↓ → Move between addresses. A click or tap works too.
Return Open the address. Interface 2037 opens the inquiry prompt. The others show a readout: try Navigation, Time, Life Support, and Command.
Esc or Address matrix Back to the matrix, from a readout or from an empty inquiry prompt.
Any key Mother answers a character at a time. A key skips to the end of the answer, and what you type waits on the next line.

From the script

Commands as the movie shows them.

The commands are connected where that makes sense. Dallas asking "What are my chances?" only makes sense inside his conversation with the computer.

They're listed in the movie's order. Run them however you like, but to act out the movie, play along with each scene.

Dallas queries the computer

CommandWhat happens
What's the story mother? The movie never shows the answer. This assumes Dallas got a relevant summary of the mission, but not the whole story.

Dallas asks how to kill it

CommandWhat happens
Request evaluation of current procedures to terminate alien An unhelpful response.
Request options for possible procedure Another unhelpful response.
What are my chances? The most unhelpful response yet. (It's more gripping in the movie.)

Ripley queries the computer

CommandWhat happens
Request clarification on science inability to neutralize alien An unhelpful response, but it starts a revealing conversation.
Request enhancement The plot thickens.
Emergency command override 100375 Grants access to the details of special orders. The movie spells it "overide", so that works too.
What is special order 937? A key plot point, if you have access.
