Launch terminal

Commands

Tron won't start: the address file is empty. Find it.

Dillinger has suspended all Group 7 access, which Alan's screen in the film calls priority access 7. Alan is in Group 7. The terminal is on screen only briefly, so most of this fills it out as a Unix of the "future". Poking at what the MCP guards makes it suspicious, and it may log you out. You keep what you've done. Tab completes commands and paths, the ones Alan can see. Select a command to open the terminal and run it there.

CommandWhat happens
service start [service]
service stop [service]

Starts or stops a service: tron or mcp. Tron won't start while its address file is empty.
mail
mail [number]

Reads Alan's mail. At the & prompt, type a message number to read it, h to list messages, ? for help, or q to quit.
date

The date and time on Alan's terminal at the start of TRON, in ENCOM's Pacific time, written the way his screen writes it.

The clock keeps running, so each run gives a different time.
ls [-a] [-l] [path]

Lists a directory. -a shows hidden files and -l shows owners and permissions.
cd [path]

Changes directory. ~ is Alan's home.
pwd

Prints the current directory's path.
cat [file]

Prints a file.
head [-n] [file]
tail [-n] [file]
wc [-lwc] [file]
grep [-c] [-i] [-n] [-v] [pattern] [file]
sort [-r] [-n] [-f] [file]
uniq [-c] [file]

The first or last lines of a file, its counts, the lines that match, the lines in order, and repeated lines once. Without a file, each reads from a pipe: ls -l | grep group7, who | wc -l, strings /tmp/core | wc. The shell expands * and ? in directories Alan can read. ENCOM has a lot of employees: try grep -i mcp /home/*/.plan or grep Laser /etc/passwd.
command > file
command >> file
command < file
command 2> file

Output into a file (emptying it first), onto the end of one, input from one, and errors into one (2>/dev/null hides them). Alan can only write where the permissions let him: who | sort > /tmp/who, then wc -l /tmp/who. As in any sh, sort f > f empties f before sort reads it.
file [file]
strings [file]
what [file]

What a file holds, the text inside a binary, and its SCCS version strings: who wrote each part, and when. Some files the MCP won't let you read.
chmod [mode] [file]
touch [file]
mkdir [dir]
rmdir [dir]

Changes a file's mode (in octal, like 644), makes files and directories, and removes empty ones, where Alan's permissions allow.
cp [from] [to]
mv [from] [to]
rm [file]

Copies, moves, or removes files, where Alan's permissions allow.
who
query [user]

Who's logged in. query, ENCOM's version of finger, looks someone up, plan and all.
last
last [user]

Who's logged in over the last few days, and from where. Someone keeps dialing in at night.
id
groups
newgrp [group]
su [user]

Alan's user and groups, or anyone's (id flynn). Group 7 is suspended, so it doesn't count. Trying to switch groups or users gets the MCP's attention.
talk [user]

Talks to someone who's logged in, if they'll answer.
whoami
ps
ps aux
kill [-9] [pid]

Who you are, what's running (ps aux or ps -ef for everyone's), and stopping it. The MCP is always running.
request [...]

Asks the MCP for something, the way Alan does in the film: REQUEST: MASTER CONTROL PROGRAM RELEASE TRON JA 307020. With Group 7 suspended, it isn't in a giving mood.
uptime
uname -a
hostname
cal [[month] year]

About the system, and a calendar (this month, or a year). Try September 1752.
echo $HOME
env
history

The shell's variables, and what you've typed (kept across visits).
space_paranoids
matrix_blaster

The games in /usr/games, credited to Dillinger. They need an arcade cabinet. You can run them, but the MCP has sealed them against reading.
help
man [command]

Lists every command: ENCOM's own, the system's, the shell's, and the games. help [command] or man [command] describes one.
exit
logout

Logs Alan out, and back in. Files stay as they are.
clear

Clears the screen.

Walkthrough

Spoilers, for if you're stuck.

Show the walkthrough
  1. Read your mail: mail, then 3. Lora's been running a copy of TRON in the laser lab.
  2. ls /lab/laser is denied, and ls -l /lab shows why: you can't list the lab directory, but you can read a file in it if you know the name.
  3. query lora, talk lora, or ps aux names today's log: cat /lab/laser/log.0922. (Today is date: SEPT 22.)
  4. The log says she saved it as addr.bak: cp /lab/laser/addr.bak tron.addr
  5. service start tron

Off the path: cat /usr/adm/messages shows who's been dialing in and what the MCP did about it, and strings /tmp/core shows what CLU was looking for.

There's a second ending for anyone who remembers what Flynn types at the terminal in the lab.
