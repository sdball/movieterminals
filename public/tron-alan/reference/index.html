Commands

None of these are actually in the movie.

The terminal is on screen only briefly, so these fill it out as a Unix of the "future".

CommandWhat happens
service start [service]
service stop [service]

Tries to start or stop a service. Known services:

  • tron
  • mcp
date

The date and time on Alan's terminal at the start of TRON, in ENCOM's Pacific time, written the way his screen writes it.

The clock keeps running, so each run gives a different time.
ls Lists the files and directories in the current directory.
cat [filename] Prints the contents of a file.
pwd Prints the current directory's path.
help Lists every command.
clear Clears the screen.
